# 🛡️ Ark Vault — Digital Family Continuity OS

> **A 100% private, zero-cloud household operating system and emergency continuity vault designed for dual-career couples and the 30–45 Sandwich Generation. Packaged as an instant one-time digital download ($39–$49).**

---

## 🌟 What Ark Does
Ark eliminates the invisible cognitive load of running a modern household while providing an airtight, automated **72-Hour In-Case-of-Emergency (ICE) Continuity Runbook**:

1. **72-Hour Crisis Continuity Runbook**:
   - **Hours 0–24:** Immediate survival checklist, emergency contacts, employer death benefits, cash reserve access.
   - **Days 2–7:** Life insurance policy claims, mortgage auto-draft verification, utility continuity.
   - **Days 8–30:** Living trust & will execution, legal minor guardianship designations, healthcare directives.
2. **Household Institutional Memory**:
   - Main water shutoff valve location, breaker box, HVAC filter size, recurring auto-pay maps.
3. **Sandwich Node (Aging Parents Care Hub)**:
   - Tracks Medicare info, primary cardiologists/physicians, medications, durable power of attorney (DPOA), and senior fraud locks.
4. **Ephemeral Sitter & Caregiver Passes**:
   - 1-click shareable mobile briefings for babysitters and grandparents with emergency contacts, kid allergies, bedtime routines, and pediatrician numbers.
5. **1-Click Printable Family Emergency Binder**:
   - Clean, professional `@media print` legal binder ready to print and store in a home fireproof safe.
6. **100% Offline & Private Local Storage**:
   - Zero cloud servers. All information saves to the user's browser `localStorage`, with 1-click JSON backup and restore.

## 🚀 Quick Start (Testing Locally)

Run the local server:
```bash
python server.py
```
Open **[http://localhost:5000](http://localhost:5000)** in your browser.

Or simply double-click **`Start-Ark.bat`** (Windows) or **`public/index.html`** in any browser.

## 📦 Building the Digital Release Package

To generate the customer-facing distribution zip file:
```bash
python package_release.py
```
This produces `Ark-Family-OS-Digital-Edition.zip` ready for direct upload to **Gumroad, Etsy, Lemon Squeezy, or Stan Store**.
